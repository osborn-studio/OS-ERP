# 批次 N 反例先红后证 · 反例 A：期初滚动少算一期

## 注入内容（改代码，不改数据）

文件：`server/lib/report.js` → `openingBalancesAsOf()` 的滚动区间终点

```
-      .all(base.period, p)
+      .all(base.period, shiftPeriod(p, -1))   // 反例注入 A：滚动终点前移一期
```

含义：某期间的"期初"少滚了**上一个月**的发生额。这是一个非常真实的缺陷形态
（区间终点算错一个月），而它**不会让任何账不平** —— 因为它少掉的那一期
自己的借贷本来就是平的（Σsigned = 0）。

⚠️ `auditReport(period=2026-10)` **一声不吭**：偏差全部落在 2026-09，
而 2026-10 的前两期都没有发生额，在那一期上看不出差异。
**"只检查我正在看的那一期" = 覆盖面盲区**（比断言少更危险：盲区是"以为覆盖了"）。

→ 据此把探针⑦从"只查本期"改成**全期间扫描**（与同批第 ⑥ 条结转探针的全表扫描对齐）。
