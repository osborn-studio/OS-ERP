## 注入内容

文件 server/lib/report.js → buildReportCSV()

    -  const cols = result.columns && result.columns.length ? result.columns : columnsOf({ period: result.period })
    +  const cols = [ 行次 / 项目 / 金额 / 本年累计 / 基期 / 差额 / 变动率% ]   // 反例注入 D

含义：这正是**本批要消灭的旧形态** —— 服务端 CSV 自己定义一套列，前端表头另定义一套。
两处定义的后果不是"报错"，而是"文件里的列名和屏幕上的不一样"，
而这件事**没有人会去核对**（它完全不像一个错误）。
这里的注入还额外把中文名写短了（"金额"而不是"本期金额(2026-10)"）——
连"这是哪一期"都没了，拿去开会只能靠文件名猜。
