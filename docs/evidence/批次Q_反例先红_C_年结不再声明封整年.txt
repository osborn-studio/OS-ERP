# 批次 Q 反例先红后证 · 反例 C：年结不再声明"封整年"

## 注入内容

文件 server/lib/period-audit.js → PERIOD_ACTIONS

    -  annual_carry: { ..., effect: { annual_voucher_id: 'voucher', period_status: 'closed', spread_year: true } }
    +  annual_carry: { ..., effect: { annual_voucher_id: 'voucher' } }   // 反例注入 C

含义：日志照写、凭证照生成、**整年也确实被 closed 了**（那段 `UPDATE` 一行没动），
只是**动作表里不再声明"这个动作会扩散到整年"** ⇒ 重放不再把这一年的其它期间置为 closed。

这正是本批"效果只声明一次"要防的那类缺陷：改的是**声明**，账上一切正常 ——
它唯一的症状是"日志解释不出这一年的 3 月为什么是已关账的"。

## 预期

PERIOD_AUDIT_DESYNC 必须在**非 12 月**的期间上响；Q6 的"1 月也被年结封成已关账"红；
Q1 的"只有年度结转会扩散到整年"也应当红（动作表本身被改坏了）。
