## 注入内容

文件 server/lib/annual.js → annualPrecheck()

    -  if (pending.length) {
    +  if (false && pending.length) {   // 反例注入 A

含义：年结不再要求"全年每个月都做过月度结转"。
后果不是"少转一笔"，而是**一笔永久错账**：年结把 4103 转到 4104 并把它归零，
而未结转过的那几个月，损益仍然挂在 6xxx 上 —— 它们已经错过本年度唯一的年结窗口。
**而账仍然是平的**（资产 = 负债 + 权益照样成立），所以只有这条检查能拦住它。

## 第一次跑（用例只有"一个月都没结转"）：只红 2 条 —— 用例不够锋利

第一次只红 2 条，因为那时 4103 的余额是 0，`ANNUAL_NOTHING`（"没有需要结转的内容"）
**恰好替它兜住了**。但那条检查在"**部分月份已结转**"时完全不管用（余额非 0），
而那才是真正会静默出错的情形。→ 据此补了一个"部分已结转"的用例。
