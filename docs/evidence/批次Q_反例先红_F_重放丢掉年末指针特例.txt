# 批次 Q 反例先红后证 · 反例 F：重放丢掉"年维度指针只挂年末"这条特例

## 注入内容

文件 server/lib/period-audit.js → replayEntries()

    -  if (e.scope === 'year' && p !== `${e.scope_key}-12`) continue
    +  /* 反例注入 F：不再区分"年维度指针只挂年末" */

含义：年结 / 分配的凭证指针**只写在年末那一行**（`UPDATE ... WHERE period=YYYY-12`）。
重放若不区分这件事，就会把 12 月的年结指针**加到这一年的每一期上** ——
于是 1 月的重放结果里凭空多出一个"年结凭证"，而期间表上那一行当然是 NULL。

## 这一组反例的性质与前面五组不同：它制造的是**假红**

前五组都是"实现坏了、探针该响"，而这一组是"**探针坏了、对着正确的账报红**"。
假红比漏报更消耗信任：一旦运维见过几次"明明没问题却报红"，
下一次真红时他的第一反应是"又是误报"。

所以这类缺陷必须**由测试里一条明确的断言**挡住 ——
Q6 的"1 月**不会**拿到别人的年结指针"就是它（期望 null，实际 19）。
