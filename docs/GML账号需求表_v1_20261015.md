## 填写说明

1. **一行一个账号**，多人同一角色就多行。
2. 「姓名」可填真实姓名或「张*」形式；「登录名」可填手机号后四位或自定义。
3. 「数据范围」填其一：**全部 / 指定区域 / 指定门店 / 指定经销商**。
4. 「审批额度」填该角色能批的最高金额（人民币）；不适用的填「—」。
5. 空白角色表示暂不需要 → 留空即可。
