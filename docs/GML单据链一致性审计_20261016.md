# GML 单据链一致性审计登记（批次 V · 2026-10-16）

> **起因**：用户指令 —— *"功能不再增加，就是修好原来的内容；钉钉和飞书缺实际环境，可以放一放；关键所有单据逻辑都是通的，不要有 bug，彼此都是串联在一起的，前后逻辑一致。"*
>
> **做法**：按**单据链**分五路只读审计（采购 / 销售 / 库存 / 制造·委外·质检 / 内核·状态机·前后端接线·财务），
> 全部在 `/tmp` 下的**独立库副本 + 独立端口**上实测，**未触碰 `data/` 下三个开发库**，审计期**未改任何源码**。
>
> **本文件是缺陷登记**（"修完"的定义见文末）。**不含新功能**：所有建议修法都限定在"改判据 / 改校验 / 改同步 / 补字面路由"，**不加表、不加权限点、不新增业务域**。

## 四、"修完"的定义（本项目既有纪律）

1. **反例先红后证**：先造一个能把它变红的注入，红断言原文可读 → 还原 → 回绿。
