# 伴圆AI原生ERP 本地交付验收与范围

交付日期：2026年10月21日。业务版本包括本轮代码审查修复，本地安装工具与手册一并交付。本说明用于区分已经验证的本地交付能力与仍需客户项目验证的范围。

## 已执行验证

1.0.0初版本已从实际 ZIP 解压到带中文及空格的全新路径，不使用原机 node_modules，不复制原机数据库，在 macOS Apple Silicon 和 Node.js 22.22.2 上完成首次联网安装及42项验收。1.0.1安全升级新增依赖审计和回归，具体安全边界见06_依赖安全说明.md及新版交付验收记录。

- 发布文件完整性校验、全新运行依赖安装、SQLite 原生模块加载及首次建库。
- 十个演示角色登录，美妆及餐饮总部查询，门店 POS 上下文，经销商本人订货中心及总部访问拒绝。
- 登录、POS、商城页面，前端构建资源，四份 HTML 手册和消费者商品数据接口。
- MCP 签发只读令牌、发现工具、读取单据类型，以及随包只读示例。
- 重复安装保留配置，端口冲突不停止已有服务，诊断工具及非法外部数据路径隔离。
- 停机一致性备份、重启保留新增用户、按安装手册在新目录恢复并重新登录。
- 文件被改动时完整性校验失败，业务数据及备份新增不影响发行文件校验。

另完成 TypeScript 检查及 Vite 构建。网页手册经过浏览器实际打开，检查中文、表格、目录及相互跳转。构建仍存在前端单包体积提示，不影响本次构建成功，但后续可做按路由拆分优化。

此前1.0.0业务代码审查完成美妆、餐饮连续三轮全量回归，每轮111项无失败。1.0.1安全升级后重新完成连续三轮全量回归，每轮112项通过、0项失败，累计24873条断言；另在全新中文及空格路径完成44项安装验收，包含新增安全手册访问和运行安装不包含构建漏洞依赖链。实际浏览器复核了管理员订单详情与返回、经销商订货中心、门店POS入口，未出现浏览器警告或错误日志。以上均不等同于跨平台全量测试或完整渗透测试。

## 未作出的承诺

Windows、Linux、Docker 未在本次环境完成实机验证。源码和启动脚本已提供，但不把“提供步骤”等同于对应平台验收通过。

未提供通用断网首装包、Node运行时或外部模型额度。首次联网安装成功后，基础 ERP 业务可在本地运行；模型调用、真实支付、短信、IM、银行、税控和企业系统接口需要各自服务与集成。

默认演示账号和固定商城验证码只用于本地演示。正式生产、公开访问、大规模并发、灾备和客户特定核算规则需单独建设和验收。服装及跨自然年度结转不在当前已完成交付范围。
