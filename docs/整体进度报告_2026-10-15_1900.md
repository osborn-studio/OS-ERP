## 六、风险与下一步

### 技术债（3 条，待主编写确认后处置）

1. **`react-router-dom` 实装 6.30.6，命中 2 个生产级 CVE**（CVE-2026-53669 开放重定向、CVE-2026-53666 反序列化构造函数注入）。这是 Dependabot 8 条告警中**唯一影响生产**的一条，修复需升至 7.18.0+，属破坏性升级，须回归 `App.tsx` 与全部 `useNavigate`/`Link` 调用点。
2. **前端运行时库误放 `devDependencies`**：`react` / `react-dom` / `react-router-dom` / `recharts` / `lucide-react` 均在 dev 段。两个后果 —— 漏洞被 GitHub 标为 "development" 易被忽略（但它们会打进生产 bundle）；部署环境执行 `npm ci --omit=dev` 时**前端根本构建不出来**。仅改分类不改版本，风险低，建议优先做。
3. **`server/lib/pricing.js:60-72` 用表名当特性开关**：以「`promotions` 表是否存在」判断促销价能力，命中后按 `price`/`sku_id`/`start_at`/`end_at` 四列查询；而 medusa 式模型无此四列 → 表一建出，取价引擎每次调用即抛 `no such column: price` → `seedOrderCenter` 崩溃 → 服务起不来（已实测复现，服务 240s 未就绪）。**做批次 F 前必须先改**。
