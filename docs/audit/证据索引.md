## 范围和机器可复核证据

- `evidence/remote-tree.json`：完整当前树；许可文件、工作流等不存在的判断基于此清单。
- `evidence/source-file-manifest.csv`：777 个文件的原始 Git blob SHA1 和 SHA256 校验。
- `evidence/clone-provenance.json`：clone 路径、remote、分支、commit、完成时间及剩余历史对象。
