# ADR-0003：首次生产管理员初始化

日期：2026-10-22。范围：本机首次初始化，不是公开注册或密码重置功能。

## 决定

由 `scripts/bootstrap-admin.mjs` 接收非秘密参数，通过标准输入读取一行密码，然后初始化所选行业数据库的 schema。必须显式设置 `GML_RUNTIME_MODE=production` 和绝对路径 `GML_DATA_DIR`；缺省运行模式也不构成执行初始化的明确选择。已有数据库必须通过生产分类校验，demo/test 库不能采用。

用户表为空、没有非系统业务组织且不存在一次性标记，才允许建立首管理员。组织、用户、`user_roles`、`user_orgs`、核心组织职能、审计记录及 `os_egp_admin_bootstrap` 标记在同一 `BEGIN IMMEDIATE` 事务中提交。重复调用或并发败者必须拒绝，不修改已存在的密码。标记不以外键关联用户：即使账号被删除，也不能再次进入 bootstrap。

企业组织为单一根组织、法人主体和自身货主，本位币固定 CNY。管理员设置 `role=admin`、`is_super=1`、`data_scope=all`，建立现有权限系统需要的角色与组织关联。仅启用采购、销售、库存、财务的组织职能，不生成商品、订单、资金单据或 Agent 凭据。

密码最少 16 个 Unicode 字符、最多 72 个 UTF-8 字节、至少 6 种字符，不允许控制字符；拒绝超长输入而不是触发 bcrypt 静默截断。使用现有 bcrypt 格式，cost=12。此规则不是密码熵保证，也不是完整账号密码治理；后续仍需统一注册/改密/重置策略及会话撤销。

CLI 不接受密码参数或密码环境变量，不回显密码、哈希、SQL 异常详情。输入超过 128 字节或 30 秒未结束时拒绝；CLI 创建新文件时使用 umask 077，不擅自修改已有目录权限。JS 字符串不能保证从内存彻底擦除，因此不声称防内存取证。

## 操作

不要使用 `echo '实际密码'`、命令行 `--password` 或 shell 历史中的明文。可让本机密码管理器输出到管道；在用户指定的 Linux dmserver 上也可用 Python 的隐藏输入提示：

```sh
python3 -c 'import getpass,sys; sys.stdout.write(getpass.getpass("首次管理员密码: ")+"\n")' |
  GML_RUNTIME_MODE=production GML_DATA_DIR=/absolute/new/os-egp-data GML_DB= \
  node scripts/bootstrap-admin.mjs \
  --industry=cosmetic --company-code=MY_COMPANY --company-name='企业名称' \
  --username=owner --name='管理员姓名'
```

`getpass` 通过终端隐藏输入，密码只通过管道传递，不要在录屏或调试日志中捕获管道内容。CLI 返回非秘密 JSON，包含成功状态、行业、用户 ID、组织 ID 等；它不会启动服务。随后启动服务必须另行安全配置 JWT 密钥，并只在当前开发验收范围内运行。

所选行业可为 cosmetic/food/apparel；每个行业数据库各自执行一次。这不是多个收费客户共用实例的租户模型。已有企业资料或账号的数据库不能通过该命令接管，需另行设计迁移或账号恢复流程。不得手动删除标记来“重置管理员”。

schema/migration 初始化发生在账号创建事务之前；事务回滚覆盖管理员初始化写入，不回滚此前的 schema/config 初始化。继承的迁移自愈与配置副作用仍由迁移治理任务处理。

## 验证

运行 `node --test tests/admin-bootstrap.test.mjs`。覆盖：完整账号及组织关联、空业务表、秘密不入输出、重复初始化、删除账号后的永久标记、显式生产模式、demo 库拒绝、输入错误、非空库保护、审计失败时完整回滚、两个并发进程仅一个成功，以及真实 HTTP 登录和管理员接口访问。

测试只使用新建临时目录与随机合成凭据；HTTP 验证绑定 loopback 随机端口并关闭。未测试 Windows 实机、完整采购销售业务、灾备恢复、恶意系统管理员或无文件权限的外部攻击者；本 CLI 依赖本机执行权限，不是远程安全边界。

2026-10-22 本工作树实测：macOS Apple Silicon、Node 22.22.1，最终专项测试 8/8 通过，0 跳过，约 10.6 秒；包括新数据库组/其他用户权限位为零与非法 UTF-8 拒绝。未运行完整回归，由集成任务执行。

独立复审后新增第 9 个用例：两个 CLI 同时指向完全空目录，不预建 schema。单独运行该新增用例通过（约 0.8 秒）：恰好一方成功，数据库只存在一个完整管理员、组织、角色/成员关联、4 个核心职能、审计与永久标记，外键检查为空。竞争败者可在 schema 初始化阶段明确失败或在管理员事务中返回已完成；本测试不要求历史迁移实现并发等待/重试。新增后未重跑全部 9 项，由集成任务统一执行。
