功能模块

按化妆品行业的真实经营场景组织：线上接单、线下分销、仓配履约、渠道政策与库存管控。

01线上 OMS

平台店铺授权、订单拉取、批量转单、发货回传、退款受理、可售库存推送。

  • 天猫 / 京东 / 抖音 / 美团闪购 / 自营商城
  • 转单即占用库存，避免超卖
  • 同步日志可回溯每一笔异常

02采购闭环

采购订单 → 审批 → 收货入库 → 采购退货，全流程事务化。

  • 收货自动生成批次与到期日
  • 收货进度实时回写订单
  • 按供应商维度统计在途

03多渠道销售

经销商分销、门店零售、平台电商统一订单中心。

  • 经销商自动套用等级折扣
  • 确认占库、发货出库、回款登记
  • 退货冲减应收与返利基数

04存货管理

库存、流水、收发存台账、调拨、盘点与四类预警。

  • 可售库存 = 现存量 − 占用 − 安全库存
  • 批次先进先出、同批次临期优先
  • 低于安全库存 / 临期 / 零库存 / 呆滞

05经销商管理

等级政策、信用额度、批次返利、对账单一体化。

  • 360 画像：趋势、畅销款、采购结构
  • 返利按净额自动核算并支持发放
  • 对账单期初 + 销售 − 回款 = 期末

06经营看板与系统管理

经营 KPI、待办清单、排行与库存分布；用户权限与审计留痕。

  • 8 类角色，经销商 / 门店数据隔离
  • 主数据变更与单据操作全留痕
  • 枚举字典前后端共用同一口径

部署方式

单机一条命令即可运行，可挂官网子路径或独立子域，也可作为纯静态 Demo 展示。

ADocker

免装数据库，镜像内自带 SQLite，数据挂载卷持久化。

  • docker compose up -d
  • 默认端口 3001

B本机 Node

Node 20+ 环境，安装依赖后构建启动。

  • npm install && npm run build
  • npm run seed && npm start

C挂官网

内网端口 + 官网反向代理，或独立子域跳转。

  • Nginx location 反代
  • 静态包可单独托管
