伴圆AI原生ERP 依赖安全说明

版本：1.0.1，日期：2026年10月21日。本文解释GitHub依赖告警、本轮修复和剩余风险。安全告警代表第三方库存在已知漏洞，不等于系统已被攻击，也不能把功能测试通过理解为没有安全风险。

一 本轮处理

升级前GitHub共有12条开放告警，覆盖6类依赖。以下11条有官方修复版本，已在本轮升级到不受对应公告影响的版本；braces公告其后已被GitHub撤回（见第二节更新）。

依赖原版本本轮版本处理范围
Vite5.4.216.4.5路径访问限制、Windows编辑器调用等6条公告
esbuild0.21.5随Vite升级至0.25系列开发服务器跨站读取公告
React Router6.30.67.18.4跳转及SSR解析2条原有公告，并避开7.18.0新增受影响范围
fflate0.8.20.8.3畸形ZIP64触发解压死循环公告
postcss-selector-parser6.1.47.1.7特制选择器导致CPU消耗公告，以npm override固定
braces3.0.33.0.3公告已撤回（2026-10-24），仍限制使用场景

Vite开发服务器显式监听127.0.0.1。没有升级业务数据库和业务规则，没有更换现有Tailwind 3样式体系。React Router涉及主版本升级，因此需额外验证真实页面登录、跳转及角色入口，不能只看编译通过。

二 剩余高危告警

更新（2026年10月24日）：下述braces公告GHSA-vfj7-8cjw-p6xm已被GitHub撤回（Withdrawn Advisory，理由是不属于实际可利用的漏洞），官方审计不再列出braces及其上游链。以下内容保留为历史记录，其中"保留告警""暂无官方补丁"的表述不再适用；暂行限制作为良好做法仍可沿用。此前运行依赖审计唯一的高危条目是zod（GHSA-mrhx-c7xc-m3w5）：该依赖在代码中没有任何引用，现已从依赖中移除，限期白名单随之清空，持续集成的审计门禁仍然保留，详见docs/security/dependency-notes.md第9节。

公告：GHSA-vfj7-8cjw-p6xm，CVE-2026-93687。GitHub公告将braces 3.0.3及以下版本列为受影响，修复版本为None。特制的深层嵌套花括号匹配模式可能耗尽调用栈，使Node进程退出，属于拒绝服务风险。

本项目由Tailwind的文件匹配及监听依赖间接引入braces。现有文件匹配模式写在受维护者控制的tailwind.config.js中，普通业务表单没有被设计为接收并执行任意构建glob。基于当前调用方式，主要暴露在开发和构建链，而不是普通业务API；这是对当前代码路径的风险判断，不是漏洞已经修复的结论。

暂行限制：

  • 不把开发服务器开放到公网，也不将npm run dev作为客户生产运行方式。
  • 不把用户上传内容、业务字段或外部传入的字符串拼进Tailwind文件匹配模式。
  • 仅在可信源码目录构建，不监听未知来源目录、上传目录或可由外部人员修改的源码。
  • 普通本地安装采用已构建dist和npm ci --omit=dev，运行依赖中不安装Tailwind或braces。
  • 保留GitHub告警，持续以官方公告和修复版本为准，不标记为“误报”或“已解决”。

影响评估的依据（npm ls braces --all --package-lock-only 的依赖链输出、运行依赖树中没有 braces、各位置是否可达、重新评估的触发条件和未验证项）记录在仓库内 docs/security/dependency-notes.md。

彻底移除该依赖需要迁移样式构建链或等待上游补丁。迁移Tailwind主版本会影响全站生成样式和兼容性，需要独立安排界面回归，未在本轮仓促实施。

三 检查方法与口径

node scripts/test-dependency-security.mjs
npm audit --json --registry=https://registry.npmjs.org
node scripts/check-audit-allowlist.mjs
npm audit --omit=dev --json --registry=https://registry.npmjs.org

新增依赖回归检查锁定版本、ZIP中文往返、畸形ZIP64及时退出、路由匹配及CSS解析兼容性。构建后的样式按PostCSS解析并规范化无意义空白后比较，1294条声明一致。

全依赖npm audit仍会显示braces及chokidar、fast-glob、micromatch、tailwindcss共5个受影响包。这些条目源于同一条未修复公告，不应描述为额外修复了5个独立漏洞。只审计运行依赖时未发现已知公告，不代表已证明业务代码、浏览器包和部署环境绝对安全。

完整业务回归、实际浏览器检查及新版安装验收结果以本次交付记录为准。GitHub依赖分析为异步处理，远程告警关闭状态需在推送后复核，不预先声称平台已经清零。
