## 二、三步开始演示

### 第 1 步：装

1. 解压 `01_演示程序/伴圆ERP-演示版-20261017.zip`（约 25MB，解压到任意目录，**路径不要带空格也行，但别有中文特殊符号**）
2. 电脑需先装 **Node.js 18+**（<https://nodejs.org/zh-cn> 下载 LTS，一路下一步）
3. 双击解压出来的 **`启动.command`**（Mac）或 **`启动（Windows）.bat`**（Windows）
   - 首次会联网安装依赖，1~3 分钟；之后每次启动只要几秒
   - Mac 若提示"无法验证开发者"：右键点它 → 打开 → 再点"打开"

### 第 2 步：登

浏览器会自动打开 **http://localhost:3001/login**

**选行业版本 → 点一张角色卡片（账号密码自动填好）→ 登 录**

| 角色 | 账号 | 密码 | 登进去能看到什么 |
|---|---|---|---|
| 系统管理员 | `admin` | `12345` | 全部菜单 + 系统设置 + AI 与 MCP 控制台 |
| 老板 / 总经理 | `boss` | `123456` | 全部数据只读 + 关键审批 |
| 供应链主管 | `scm` | `123456` | 采购 / 库存 / 生产 / 质检；销售财务只读 |
| 采购 / 销售 / 仓储 / 财务 | `purchase` `sales` `warehouse` `finance` | `123456` | 各自业务域 |
| 门店店长 | `store01` ~ `store05` | `123456` | 本店 POS / 库存 / 要货 |
| 经销商 | `dealer01` | `123456` | 订货中心 + 对账单（仅美妆/服装） |
| 只读访客 | `viewer` | `123456` | 只看不改 |

> 连锁餐饮版**没有经销商**（总部直营门店），菜单里不会有「经销商管理」。

### 第 3 步：讲

打开 **`02_演示手册`**，按里面的顺序走：

- 开场三句话（30 秒定调）
- 美妆主线 7 步（约 25 分钟）
- 连锁餐饮差异版（约 15 分钟）
- 按角色演示路径 / 常见追问 / 翻车急救 / 45 分钟与 20 分钟两套节奏

## 三、演示数据里已经准备好什么

- **连续 22 个营业日**的门店零售与日结批次（美妆 5 店 / 餐饮 20 店），**每天都有生意**，不是只有今天
- 销售：4 张「**发 60% / 开 60% 票 / 收 40% 款**」的中间态订单
- 采购：**部分入库 / 在途未到 / 已到待检 / 已检** 四种形态
- 完整主数据 + 业财一体凭证 + 三大报表
- 三套独立库：美妆连锁、连锁餐饮、服装（开发中，入口不展示）

> 全部数据由程序生成，**不含任何真实客户、真实价格或商业机密**。系统首页顶部有 `DEMO 演示系统` 标识。

## 四、常见问题

| 问题 | 处理 |
|---|---|
| 端口 3001 被占用 | Mac/Linux：`PORT=3002 npm start`；Windows：`set PORT=3002 && npm start` |
| 页面打不开 / 一片空白 | 确认黑色终端窗口还开着（关掉就停服务）；再看终端有没有报错 |
| 演示点乱了想恢复 | 在程序目录执行 `npm run reseed`（约 10 秒，账号密码与单据全部复原） |
| 换电脑能用吗 | 可以。整个目录拷过去，重新 `npm install --omit=dev`（原生模块不能跨平台复用） |
| 想多人同时看 | 局域网访问 `http://<本机IP>:3001/login`（演示用，不建议当生产） |
| 只想看手册 | 直接双击 `04_网页版手册/demo-flow.html` |
